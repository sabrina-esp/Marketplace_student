# 📱 PWA Icons - Instructions

## ⚠️ IMPORTANT : VOUS DEVEZ GÉNÉRER LES ICÔNES !

### Étape 1 : Ouvrez le générateur d'icônes

Cliquez sur ce lien ou copiez-le dans votre navigateur :
```
http://localhost:3011/icons/icon-generator.html
```

### Étape 2 : Téléchargez toutes les icônes

1. Sur la page du générateur, cliquez sur le bouton **VERT** :
   ```
   ⬇️ Download All Icons
   ```

2. Les fichiers suivants seront téléchargés :
   - icon-72x72.png
   - icon-96x96.png
   - icon-128x128.png
   - icon-144x144.png
   - icon-152x152.png
   - icon-192x192.png
   - icon-384x384.png
   - icon-512x512.png

### Étape 3 : Copiez les fichiers ici

1. Allez dans votre dossier **Téléchargements**
2. Sélectionnez TOUS les fichiers `icon-*.png`
3. Copiez-les dans CE dossier : `public/icons/`

### Étape 4 : Vérification

Une fois les fichiers copiés, ce dossier doit contenir :
```
public/icons/
├── icon-72x72.png
├── icon-96x96.png
├── icon-128x128.png
├── icon-144x144.png
├── icon-152x152.png
├── icon-192x192.png
├── icon-384x384.png
├── icon-512x512.png
├── icon-generator.html
└── README.md (ce fichier)
```

### Étape 5 : Testez !

1. Ouvrez http://localhost:3011
2. Attendez 5-10 secondes
3. Une bannière violette ou un bouton apparaît
4. Cliquez pour installer !

---

## 🎨 À quoi ressemblent les icônes ?

Toutes les icônes ont :
- Un fond dégradé violet (couleur de votre marque)
- La lettre "M" blanche (pour Marketplace)
- Un petit chapeau de diplômé (symbole d'éducation)
