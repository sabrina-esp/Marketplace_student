## 🎯 Les 12 Phases en Détail

### Phase 1️⃣ : Découverte (Jour 0)
- **Objectif** : Attirer et engager
- **Actions** : Visite web → Bannière PWA

- **Objectif** : Créer un compte
- **Actions** : Formulaire → Email vérification

### Phase 3️⃣ : Installation (Jour 0)
- **Objectif** : App native
- **Actions** : Install prompt → Home screen

- **Objectif** : Premier engagement
- **Actions** : Explorer → Inscription cours

- **Objectif** : Appropriation
- **Actions** : Avatar → Bio → Dark mode
- **Résultat** : ✅ Profil complet

### Phase 7️⃣ : Offline (Jour 10)
- **Objectif** : Disponibilité totale
- **Actions** : Métro → Cache → Sync
